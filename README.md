# EduFlow

> A modern learning management system for a better way to learn.

Built with [Next.js](https://nextjs.org/), [Sanity](https://www.sanity.io/), and [Clerk](https://clerk.com/).

## Getting Started

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000) to view the app.

## Tech Stack

- Next.js
- TypeScript
- Sanity CMS
- Clerk Authentication
